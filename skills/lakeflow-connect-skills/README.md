# Lakeflow Connect skills

Category folder for skills related to **Databricks Lakeflow Connect** — ingestion
connectors (Salesforce, Veeva, Workday, ServiceNow, SQL Server, etc.), pipeline
creation/monitoring, and troubleshooting.

Add each skill as its own subfolder with a `SKILL.md`, e.g.:

```
lakeflow-connect-skills/
  create-veeva-connector/SKILL.md
  monitor-ingestion-pipeline/SKILL.md
```

(Sibling of `genie-creation-skills/`, both under the common `~/.claude/skills` folder.)
